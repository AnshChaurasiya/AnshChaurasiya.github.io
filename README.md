# 💫 The Developer's Odyssey — Ansh Chaurasiya

A cinematic, story-driven portfolio showcasing my journey as a Full Stack Developer & AI/ML Engineer.

## 🚀 Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** TailwindCSS + CSS Modules
- **Animation:** GSAP, Framer Motion
- **3D Graphics:** React Three Fiber (R3F), drei
- **State:** Zustand
- **Icons:** Radix UI Icons
- **Forms:** Web3Forms

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🏗 Project Structure

```
├── app/                    # Next.js App Router
│   ├── layout.tsx         # Root layout
│   └── page.tsx           # Home page
├── src/
│   ├── components/        # React components
│   │   ├── common/       # Shared components
│   │   └── worlds/       # World-specific components
│   ├── animations/        # GSAP/animation logic
│   ├── store/            # Zustand stores
│   ├── hooks/            # Custom React hooks
│   ├── styles/           # Global styles
│   └── assets/           # Images, icons, data
├── public/               # Static assets
└── tests/               # Unit & integration tests
```

## 🎨 Design Philosophy

This portfolio follows **The Developer's Odyssey** design system:
- **Cinematic Immersion:** Atmospheric, layered, animated UI
- **Spatial Depth:** Parallax, blur, glows, gradients
- **Soft Minimalism:** Gentle glows, smooth corners, glassy layers
- **Story-Driven:** Every element reflects a journey of growth and mastery

## 🌌 World Themes

1. **Awakening Grove** (Origin Forest) - Greenish glow, emerald mist
2. **Trial Peaks** (Logic Mountains) - Ice blue, snow white
3. **Creation District** (Neon City) - Neon pink, electric cyan
4. **Future Constellarium** (Galaxy World) - Star white, cosmic purple
